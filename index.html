Linux-terminaalin pikakierros

Linux-terminaali helposti luettavana...

Mikä on terminaali?

📚 Komentorivikäyttöliittymä (CLI)

Tekstipohjainen tapa ohjata tietokonetta ilman graafista ikkunointia (GUI).

💻 Kuori (Shell) välissä

Terminaali on vain ikkuna. Varsinainen tulkki (esim. Bash tai Zsh) kääntää komentosi käyttöjärjestelmän ytimelle.

🌍 Palvelinten standardi

Linux-palvelimilla ei usein ole graafista työpöytää. Terminaali on ainoa tapa hallita niitä.

Ennen kuin menemme asiaan otetaan pari asiaa haltuun

Mitä tulostamisella tarkoitetaan?

Kun ohjeissa puhutaan tulostamisesta, se ei tarkoita paperille tulostamista. Terminaalimaailmassa "tulostaminen" (print) tarkoittaa yksinkertaisesti sitä, että ohjelma näyttää tekstin suoraan ruudullasi.

Oleellisimmat pikanäppäimet (Nämä säästävät hermojasi)

  • ↑ / ↓ Nuolinäppäimet: Selaa aikaisemmin kirjoittamiasi komentoja (historia). Ei tarvitse kirjoittaa samaa pitkää rimpsua uudestaan.
  • Tab Sarkain (Automaattinen täydennys): Ala kirjoittaa kansion tai tiedoston nimeä ja paina Tab. Terminaali täydentää sanan loppuun ja estää kirjoitusvirheet.
  • Ctrl + C Hätäjarru: Keskeyttää ja pakottaa käynnissä olevan ohjelman tai komennon sammumaan välittömästi.

Komennon rakenne: Komento, argumentit ja flägit

Linux-komennon perussyntaksi noudattaa lähes poikkeuksetta selkeää kolmiosaista rakennetta. Tunnistat ne jatkossa näistä väreistä:

komento  [optiot / flägit]  [argumentit...]

Komento (Command)

Suoritettava ohjelma. Tässä esimerkissä cat lukee tiedoston sisällön ja tulostaa sen.

Esimerkki: cat

Argumentti (Argument)

Kohde, johon komento kohdistuu (esim. tiedoston nimi tai polku).

Esimerkki: cat loki.txt

Flägi / Optio (Flag)

Määre, joka muuttaa komennon käyttäytymistä tai tulostemuotoa.

Esimerkki: cat -n loki.txt

💡 Pro-vinkki: Lähes jokaisesta CLI-sovelluksesta saa lisätietoa ja kattavat käyttöohjeet lisäämällä komennon perään argumentin --help (esim. cat --help).
pwd

Print Working Directory

Näyttää nykyisen työhakemiston

Tulostaa (näyttää ruudulla) nykyisen työhakemiston täydellisen polun juuresta (/) alkaen.

pwd
# Tuloste: /home/opiskelija/projektit
cd

Change Directory

Vaihtaa hakemistoa

Vaihtaa nykyistä työhakemistoa järjestelmässä.

cd /var/log          # Siirry argumenttina annettuun polkuun
cd ..                # Siirry yksi hakemistotaso ylöspäin
cd ~                 # Siirry käyttäjän kotihakemistoon
ls

List

Listaa kansion sisällön

Listaa hakemistossa olevat tiedostot ja kansiot.

ls -lah /etc         # Listaa /etc -kansion sisällön flägien määrittelemällä tavalla
  • -l : Pitkä listaus (oikeudet, omistaja, koko).
  • -a : Näyttää myös pisteellä alkavat piilotiedostot.
  • -h : Ihmiselle luettavat tiedostokoot (esim. megatavut).
mkdir

Make Directory

Luo uuden kansion

Luo uuden hakemiston argumenttina annettuun sijaintiin.

mkdir projektit
mkdir -p backend/src/controllers  # Luo koko hakemistopolun tarvittaessa
cp

Copy

Kopioi tiedostoja tai kansioita

Kopioi ensimmäisen argumentin (lähde) toiseen argumenttiin (kohde).

cp config.json config.backup.json
cp -r /opt/app /backup/app        # Rekursiivinen kansion kopiointi (-r)
mv

Move

Siirtää tai uudelleennimeää

Siirtää tai uudelleennimeää ensimmäisen argumentin toiseksi argumentiksi.

mv vanha_nimi.txt uusi_nimi.txt   # Uudelleennimeäminen
mv *.log /var/log/arkisto/        # Siirto toiseen kansioon
rm

Remove

Poistaa tiedoston tai kansion

Poistaa argumenttina annetut tiedostot tai hakemistot pysyvästi. (Linuxissa ei ole roskakoria terminallissa!)

rm vanha.tmp
rm -rf /tmp/vanha_projekti        # Poistaa kansion (-r) pakotetusti (-f)
